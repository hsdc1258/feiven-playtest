# FEIVEN Playtest

Windows 10/11 x64용 FEIVEN 공개 플레이테스트 배포 저장소입니다.

## 현재 플레이테스트

- **FEIVEN R21 Public Playtest**
- 게임 빌드: `feiven-20260916-r21`
- 초기 정원: **3 대 3, 동시 한 경기(6명)**
- 경기 진행 중에는 매칭 대기열에서 빈 자리를 기다립니다. 대기열 최대48명.
- 다운로드: [R21 릴리스](https://github.com/hsdc1258/feiven-playtest/releases/tag/r21-public1-playtest)
- 설치 파일: `FEIVEN-Playtest-Setup-R21-public1.exe`
- SHA-256: `f2cc1ac7bd32a9202fed179673f54779922d7dfaa541c07a65ffd3bf3e9795e3`

이전 R20 설치본은 R21로 업데이트해야 합니다. 설치 후 FEIVEN 바로가기로 실행하고 게임 안의 로그인·로비 안내에 따라 참여하세요.

## 확인 범위

운영 HTTPS API, Linux 전용 서버 기동·배정·회수와 배포 파일 해시를 확인했습니다. 최종 설치본의 실제 6인 전투·재접속·시각·음성 검증은 아직 완료되지 않았으며 초기 플레이테스트에서 확인할 항목입니다.

서버 예산 보호에 따라 접속이나 신규 경기 배정이 일시 제한될 수 있습니다.

## Windows 안내

설치 파일 자체에는 코드 서명이 없어 Windows가 게시자를 확인하지 못한다는 안내를 표시할 수 있습니다. 릴리스에 포함된 `SHA256SUMS.txt`로 무결성을 확인할 수 있습니다.

이 저장소는 공개 플레이테스트 설치 파일 배포용이며 게임·서버 소스 코드는 포함하지 않습니다.
