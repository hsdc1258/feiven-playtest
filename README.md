# FEIVEN 공개 플레이테스트 — R20.1

> **현재 상태:** 정상 (갱신: 배포 시점) — 점검·혼잡 공지는 [Issues 상단 고정 글](https://github.com/hsdc1258/feiven-playtest/issues)과 [FEIVEN Discord](https://discord.gg/nrUy3g7gQ)에 올립니다.

FEIVEN은 개발 중인 3대3 온라인 대전 게임(언리얼 엔진 5)입니다. 이 저장소는 Windows용 플레이테스트 설치파일을 배포하는 곳이며 게임 소스나 서버 코드는 포함하지 않습니다.

## 1. 다운로드

- 릴리스 페이지: https://github.com/hsdc1258/feiven-playtest/releases/tag/r20.1-playtest
- 파일: `FEIVEN-Playtest-Setup.exe` — **약 302 MB** (302,278,948 bytes). 설치파일 하나이며 압축 해제는 필요 없습니다.
- SHA-256 (대소문자 구분 없음): `fc4b5f18d296efcbb6168afba074e9490d5565e33690b56d389a459617d2bf01`
- 게임 빌드: `feiven-20260915-r20`

- **PC(Windows)에서 받으세요.** 휴대폰으로 받으면 실행할 수 없습니다.
- 릴리스 페이지의 `Source code (zip / tar.gz)`는 게임이 아닙니다.
- **R20 설치본과 R20.1 설치본은 같은 파일입니다.** R20을 이미 설치했다면 다시 받을 필요가 없습니다. R19 이하는 현재 서버에 접속되지 않으니 제거하고 R20.1을 설치하세요.
- 다른 사이트·클라우드에 올라온 파일은 공식 배포가 아닙니다. 사용하려면 반드시 위 해시와 비교하세요.

## 2. 지원 환경

- **Windows 10 버전 1809 (빌드 17763) 이상 또는 Windows 11, 64비트 전용.** Windows 7/8.1은 설치되지 않습니다.
- 32비트 Windows와 ARM(Snapdragon) Windows는 설치는 되지만 **게임이 실행되지 않습니다.** 설치하지 마세요.
- 설치 후 디스크 사용량: 약 **435 MB** (+ Visual C++ 런타임). 다운로드 302 MB와 별도이며 임시 공간을 포함해 1 GB 정도 여유를 두세요.
- 그래픽: DirectX 11 지원 그래픽카드 필요 (기본 렌더러 DirectX 11, 기본 실행은 창 모드 1280×720).

- 음성 채팅은 푸시 투 토크 방식이며 마이크 사용은 선택입니다. 컨트롤러 지원 여부는 확인되지 않았습니다(키보드·마우스 기준).

## 3. 설치할 때 나오는 경고 (정상입니다)

설치파일에 아직 코드서명이 없어 아래 경고가 나올 수 있습니다. **보안 기능을 끄거나 백신 예외를 추가하지 마세요.** 아래 순서대로 진행하고 4번의 해시 확인을 권합니다.

1. **브라우저 다운로드 경고** — Edge: 다운로드 목록에서 `…` → `유지` → `자세히 표시` → `그래도 유지`. Chrome: `유지` → `그래도 다운로드`.
2. **실행 시 "Windows의 PC 보호" 창 (SmartScreen)** — `추가 정보` → `실행`.
3. **관리자 권한(UAC) 창은 뜨지 않습니다.** 설치는 내 계정 폴더(`%LOCALAPPDATA%\Programs\FEIVEN`)에만 이루어집니다. 관리자 권한을 요구하는 "FEIVEN 설치파일"은 공식 파일이 아닙니다.
4. **Windows 방화벽** 창은 첫 온라인 매칭 때 나올 수 있습니다. `액세스 허용`을 누르세요.

배포 전 Microsoft Defender 검사에서 탐지된 항목은 없었습니다. 다른 백신이 차단하면 예외를 넣지 말고, 해시가 일치하는지 확인한 뒤 백신 이름과 탐지명을 제보해 주세요. 작업 관리자에는 `GroundedPVP.exe` / `GroundedPVP-Win64-Shipping.exe`로 표시됩니다(내부 프로젝트 이름이며 정상입니다).

## 4. 파일이 맞는지 확인하기 (선택, 30초)

명령 프롬프트: `certutil -hashfile "%USERPROFILE%\Downloads\FEIVEN-Playtest-Setup.exe" SHA256`
PowerShell: `Get-FileHash "$env:USERPROFILE\Downloads\FEIVEN-Playtest-Setup.exe" -Algorithm SHA256`

출력이 `fc4b5f18…2bf01`이면 정상입니다(대문자로 나와도 같은 값). 다르면 실행하지 말고 다시 받으세요.

## 5. 시작하기

1. 설치 후 바탕화면의 **FEIVEN** 실행
2. 조작을 먼저 익히려면 **로컬 훈련** (로그인 불필요)
3. 온라인 플레이: **계정** 메뉴 → **Google 로그인** 또는 **기존 계정 로그인**
   - 새 아이디를 만들 때도 **기존 계정 로그인**을 누르면 브라우저가 열리고, 거기서 **회원가입** 탭을 쓰면 됩니다. 끝나면 게임으로 돌아오세요.
   - 브라우저에 열리는 로그인 페이지 주소는 **`feiven.teniv.kr`** 입니다. 다른 주소의 페이지에는 아이디·비밀번호를 넣지 마세요.
   - Google 로그인 제공 여부: <<운영자 기입 — 제공 / 미제공>>. 아이디·비밀번호 방식은 **비밀번호 찾기가 없으니** 비밀번호를 꼭 보관하세요.
4. **어둠의 성채** 선택 → **준비** → 공개 3대3 매칭. 혼자 들어가도 되고, 파티로 들어가면 같은 팀입니다.

## 7. 혼잡 시 안내 (꼭 읽어 주세요)

이번 테스트 서버는 작습니다.
- 동시에 진행되는 경기 **최대 3경기**, 경기당 6명 → **동시 플레이 18명**
- 대기열 **최대 48명**. 자리가 나면 자동으로 들어가고, 대기 중 취소할 수 있습니다.
- 대기열까지 가득 차면 게임에 `<<운영자 기입: 실제 게임 내 문구>>`가 표시되고 대기열에 들어가지 못합니다. 이때는 **1~2분 뒤 다시 준비**를 눌러 주세요. 연타는 도움이 되지 않고 다른 사람의 접속도 늦춥니다. 기다리는 동안 로컬 훈련을 권합니다.
- 경기 한 판은 대략 <<운영자 기입: 평균 경기 시간>>이며, 끝날 때마다 6자리가 비고 대기열 순서대로 입장합니다.
- 접속이 안 될 때 확인할 것: (1) R20.1 설치파일인지 (2) 서버 여는 시간인지 (3) 고정 글에 점검 공지가 있는지 (4) PC방·회사 네트워크라면 방화벽이 게임 통신(UDP 17777, 나가는 방향)을 막고 있지 않은지.
